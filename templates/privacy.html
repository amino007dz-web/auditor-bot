Privacy Policy

Last updated: 2026

Data We Collect

When you submit code for auditing, the source code is temporarily stored in memory during analysis and saved as an audit report. Reports are stored for up to 30 days and then automatically deleted.

How We Use Data

Source code submitted for auditing is used exclusively for generating security reports. We do not train AI models on your code. Anonymized vulnerability patterns (without source code) may be stored to improve detection accuracy.

Data Retention

Audit reports are stored for 30 days. You can delete your reports at any time via the dashboard. Access codes and usage statistics are retained for operational purposes.

Third-Party Services

We use Ollama Cloud for AI analysis. Source code is sent to their API for processing. We use GitHub for repository hosting. No source code is shared with any other third party.

Your Rights (GDPR)

You have the right to access, correct, or delete your data. Contact us to exercise these rights. We will respond within 30 days.

Security

All data is transmitted over HTTPS. Access codes use bcrypt-equivalent hashing. API endpoints are rate-limited and key-protected.

Contact

For privacy inquiries, please contact the administrator.
