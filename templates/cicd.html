Auditor Account

CI/CD Integration

Run automated smart contract audits in your GitHub Actions pipeline. Every PR and push gets scanned for vulnerabilities before deployment.

Setup Guide

  1. 1
    Get your API key
    Go to Account and generate an API key.
  2. 2
    Add repo secret
    In your GitHub repo: Settings → Secrets → Actions → Add AUDITOR_API_KEY.
  3. 3
    Configure below
    Fill in the form and copy the generated workflow file.
  4. 4
    Add to repo
    Create .github/workflows/audit.yml in your repo and paste the workflow.
